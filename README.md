# JEZYKOWO

Każdy język to nowy świat. Odkryj go z Językowo.
Językowo to projekt strony internetowej poświęconej odkrywaniu języków obcych. Łączy tematykę nauki języków z kosmiczną estetyką, tworząc przestrzeń, w której każdy język staje się osobnym światem do odkrycia.

Celem projektu było stworzenie nowoczesnej, atrakcyjnej wizualnie i intuicyjnej strony internetowej, która zachęca do poznawania języków obcych.
Inspiracją dla identyfikacji wizualnej jest kosmos — galaktyki, planety, orbity i gwiazdy. Każdy język reprezentowany jest przez kolorową planetę z odpowiednią flagą.

🛠️ Technologie
Projekt został zbudowany z wykorzystaniem:
HTML5 - struktura strony
CSS3 - stylizacja, responsywność i animacje
JavaScript - interakcje i funkcjonalności
Google Fonts - typografia
